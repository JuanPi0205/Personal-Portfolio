# 👨‍💻 Juan Pineda - Personal Portfolio

¡Bienvenido al repositorio de mi portafolio personal! Este proyecto es una presentación interactiva de mi experiencia, habilidades y diversos proyectos como Desarrollador Full-Stack e Ingeniero de Sistemas.

## 🚀 Tecnologías Utilizadas

Este portafolio fue construido utilizando tecnologías modernas enfocadas en el rendimiento, la escalabilidad y una experiencia de usuario fluida:

- **[Astro](https://astro.build/):** Framework web utilizado para generar un sitio estático súper rápido, permitiendo una carga casi instantánea.
- **TypeScript:** Para asegurar un tipado estricto y un código mantenible.
- **Tailwind CSS:** Para construir un diseño responsivo, veloz, y moderno.
- **Componentes Dinámicos y SSG:** Arquitectura escalable que carga la configuración de los proyectos desde archivos de datos (`src/data/projects.ts`) y los renderiza a través del robusto sistema de rutas dinámicas de Astro.

## 📁 Estructura del Proyecto

La estructura del proyecto está organizada de la siguiente manera:

```text
/
├── public/                 # Recursos públicos 
├── src/
│   ├── components/         # Componentes reutilizables de UI (Hero, About, Portfolio, Skills, etc.)
│   ├── data/               # Datos estáticos del portafolio (projects.ts)
│   ├── layouts/            # Componentes de diseño base
│   ├── pages/              # Rutas principales y dinámicas (index.astro y /projects/[slug].astro)
│   └── styles/             # Estilos globales y CSS
├── astro.config.mjs        # Configuración del framework Astro
├── package.json            # Dependencias del proyecto y scripts npm
└── README.md               # Documentación del proyecto
```

## ⚙️ Cómo ejecutar localmente

Para explorar el sitio en tu máquina local, sigue estos pasos:

1. **Clona este repositorio:**
   ```bash
   git clone https://github.com/JuanPi0205/portafolio-juanjo.git
   ```
2. **Instala las dependencias necesarias:**
   ```bash
   npm install
   ```
3. **Inicia el servidor de desarrollo:**
   ```bash
   npm run dev
   ```
4. **Visualiza en el navegador:**
   Abre [http://localhost:4321](http://localhost:4321) (u otro puerto que indique la terminal) para ver el sitio en acción.
